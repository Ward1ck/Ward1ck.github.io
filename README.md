# Ward1ck — сайт-визитка

Персональный сайт-портфолио студента-разработчика: обо мне, мои проекты, сертификаты и достижения.

🔗 **Сайт:** https://ward1ck.github.io/about-me-github/

## О сайте

- **Обо мне.** Кратко рассказываю, кто я, где учусь и какие у меня навыки. Возраст и курс считаются автоматически от даты рождения и года поступления.
- **Проекты.** Карточки с описанием, стеком и ссылками на код и демо. Есть фильтр по технологиям.
- **Достижения.** Сертификаты, хакатоны, олимпиады и курсы с фильтром по типу. Сканы документов открываются прямо на странице, поддерживаются изображения и PDF.
- **Контакты.** Ссылки для связи.
- Адаптивная вёрстка, светлая и тёмная темы.

## Стек

HTML, CSS, JavaScript без фреймворков, сборщиков и зависимостей. Хостинг: GitHub Pages.

## Структура

```
├── index.html            # разметка страницы
├── styles.css            # стили и темы
├── script.js             # отрисовка секций, фильтры, просмотр сертификатов
├── data.js               # контент: профиль, проекты, достижения
└── assets/
    ├── projects/         # скриншоты проектов
    └── certificates/     # сканы сертификатов и дипломов
```

Контент отделён от вёрстки. Чтобы добавить проект или сертификат, достаточно дописать объект в [`data.js`](data.js):

```js
// проект
{ title: "Название", description: "...", tags: ["Python"], year: 2026, github: "https://...", demo: "", image: "" }

// достижение: type — certificate | hackathon | olympiad | course
{ title: "Название", issuer: "Организация", type: "certificate", date: "2026-05",
  description: "...", file: "assets/certificates/cert.pdf", link: "" }
```

## Запуск локально

```bash
git clone https://github.com/Ward1ck/about-me-github.git
cd about-me-github
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Можно открыть и `index.html` напрямую, но тогда встроенный просмотр PDF может не работать.

## Использовать как шаблон

Сделайте форк, замените данные в `data.js` на свои и включите GitHub Pages: **Settings → Pages → Source:** ветка `main`, папка `/ (root)`.
